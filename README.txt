ADV Standing Picture Movie Tool

音声に合わせてキャラクター立ち絵と表情差分を切り替え、背景透過の連番PNGをZIPで書き出すブラウザアプリです。
メッセージウィンドウやテキスト表示はなく、キャラクター立ち絵のみを扱います。

今回の更新内容:
- 画像素材登録と連番素材登録を分離しました。
- 口パク・まばたきは「画像素材」「連番素材」の両方に対応しました。
- 口パク・まばたき用の連番素材は、セリフ中のみループ再生されます。
- セリフ終了後は、指定した「喋り終わり後の画像素材」へ自動で切り替わります。
- 退場チェックON時は、セリフ終了時にフェードアウトします。

重要:
- ベース素材・口パク素材・まばたき素材は、同じキャンバスサイズで書き出してください。
- サイズが一致していれば、位置調整なしで重ねて再生できます。
- 連番素材はファイル名順で読み込みます。mouth_001.png, mouth_002.png のような命名を推奨します。

使い方:
1. index.html をブラウザで開きます。
2. 音声ファイルを読み込みます。
3. キャラクターを登録します。
4. 画像素材登録で、通常立ち絵や喋り終わり後に使う静止画を登録します。
5. 連番素材登録で、口パクやまばたきの連番PNGを登録します。
6. キュー入力で、表示画像素材・喋り終わり後の画像素材・口パク・まばたき・位置・入退場などを設定してキューを追加します。
7. 書き出し設定から、透過PNG連番ZIPを書き出します。

補足:
- キャンバスサイズは 1920×1080 です。
- 書き出しPNGにはグリッドや安全範囲ガイドは入りません。
- JSON保存には立ち絵画像データ・連番素材・キュー情報・読み込んだ音声ファイルが含まれます。
- 音声を含めるため、音声ファイルが長い場合はJSONファイルサイズが大きくなります。
- JSZipはCDNから読み込んでいます。ZIP書き出し時はインターネット接続が必要です。
