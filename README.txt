ADV Standing Picture Movie Tool

音声に合わせてキャラクター立ち絵と表情差分を切り替え、背景透過の連番PNGをZIPで書き出すブラウザアプリです。
メッセージウィンドウやテキスト表示はなく、キャラクター立ち絵のみを扱います。

使い方
1. index.html をブラウザで開きます。
2. 画面下部の「素材・再生」から音声ファイルを読み込みます。
3. キャラクター名を登録します。
4. キャラクターごとに「笑顔」「照れ」「困り顔」などの差分名を付けて立ち絵画像を登録します。
5. 下部の入力欄で、開始秒・台詞終了秒・差分・終了後の立ち絵・位置・入場/退場・アニメーションを設定してキューを追加します。
6. 退場チェックをオンにすると、台詞終了秒でフェードアウトします。
7. 退場チェックをオンにしない場合、台詞終了秒以降は「終了後の立ち絵」に自動で切り替わり、そのキャラは次の差分変更や退場キューまで表示され続けます。
8. 編集中のキューや未保存の入力内容は、プレビューへ仮反映されます。
9. 書き出し設定から、透過PNG連番ZIPを書き出します。

補足
- キャンバスサイズは 1920×1080 です。
- 書き出しPNGにはグリッドや安全範囲ガイドは入りません。
- JSON保存には立ち絵画像データ・キュー情報・読み込んだ音声ファイルが含まれます。
- 音声を含めるため、音声ファイルが長い場合はJSONファイルサイズが大きくなります。
- JSZipはCDNから読み込んでいます。ZIP書き出し時はインターネット接続が必要です。
