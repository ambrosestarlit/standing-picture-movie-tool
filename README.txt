ADV Standing Picture Movie Tool

音声に合わせてキャラクター立ち絵と表情差分、口パク、まばたき、アニメーションを切り替え、背景透過の連番PNGをZIPで書き出すブラウザアプリです。
メッセージウィンドウやテキスト表示はなく、キャラクター立ち絵のみを扱います。

今回の更新内容:
- UI言語を日本語 / English / 한국어 に対応しました。
- ヘッダーに Language セレクトを追加しました。
- 選択した言語はブラウザに保存され、次回起動時にも反映されます。
- HTML上の固定UIだけでなく、JSで生成されるキュー一覧、ステータス、アラート、確認ダイアログ、書き出し進捗も多言語化しました。

主な機能:
- シーン管理に対応しています。
- 1プロジェクト内に複数シーンを作成し、プルダウンで切り替えできます。
- キャラクター素材・画像素材・連番素材はプロジェクト共通です。
- 音声ファイルと立ち絵キューはシーンごとに保存されます。
- シーンの追加、名前変更、複製、削除に対応しています。
- 旧形式のJSONを読み込んだ場合は、自動で「シーン1」に変換します。

素材登録:
- 画像素材登録と連番素材登録を分離しています。
- 画像素材は通常立ち絵や喋り終わり後に表示する静止画として使用します。
- 連番素材は口パクやまばたきのループ再生に使用します。
- 口パク・まばたきは「画像素材」「連番素材」の両方に対応しています。
- 口パク用の連番素材はセリフ中のみループ再生されます。
- まばたき用の連番素材はキャラが表示されている間ずっとループします。
- セリフ終了後は、指定した「喋り終わり後の画像素材」へ自動で切り替わります。
- 退場チェックON時は、セリフ終了時にフェードアウトします。

重要:
- ベース素材・口パク素材・まばたき素材は、同じキャンバスサイズで書き出してください。
- サイズが一致していれば、位置調整なしで重ねて再生できます。
- 連番素材はファイル名順で読み込みます。mouth_001.png, mouth_002.png のような命名を推奨します。

使い方:
1. index.html をブラウザで開きます。
2. ヘッダーの Language から表示言語を選択します。
3. 「シーン管理」で作業するシーンを作成または選択します。
4. 音声ファイルを読み込みます。
5. キャラクターを登録します。
6. 画像素材登録で、通常立ち絵や喋り終わり後に使う静止画を登録します。
7. 連番素材登録で、口パクやまばたきの連番PNGを登録します。
8. キュー入力で、表示画像素材・喋り終わり後の画像素材・口パク・まばたき・位置・入退場などを設定してキューを追加します。
9. 書き出し設定から、透過PNG連番ZIPを書き出します。

アニメーション調整:
- ジャンプの大きさ、ジャンプの速さ、震えの大きさ、震えの速さをキューごとにスライダーで調整できます。
- 未設定の旧キューは、ジャンプ高さ42px/速度1.0、震え大きさ8px/速度1.0として扱います。

プレビュー:
- 右側はプレビューエリアを固定し、設定エリアのみ内部スクロールします。
- PC幅では右側パネル全体をsticky表示にし、プレビューを見たまま下部設定をスクロールできます。
- 狭い画面幅では従来通り縦並びに戻ります。
- グリッドやガイドはプレビュー用です。書き出しPNGには含めません。

保存:
- JSON保存には立ち絵画像データ・連番素材・キュー情報・読み込んだ音声ファイルが含まれます。
- 音声を含めるため、音声ファイルが長い場合はJSONファイルサイズが大きくなります。
- キャッシュ保存・キャッシュ復元にも対応しています。

補足:
- キャンバスサイズは 1920×1080 です。
- 書き出しPNGにはグリッドや安全範囲ガイドは入りません。
- JSZipはCDNから読み込んでいます。ZIP書き出し時はインターネット接続が必要です。
